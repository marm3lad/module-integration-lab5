# module-integration-lab5

Лабораторная работа № 5 «Разработка и интеграция модулей проекта (командная работа)».
Вариант 6. Язык — Python.

## Задача

Даны два двумерных массива целых чисел (не больше 10x10).
Для каждого массива указать количество строк, в которых чётность элементов
чередуется, а в чётных строках второй элемент нечётный.
Если таких строк нет ни в одном массиве — вывести сообщение.
Проверка строки — отдельная процедура, в неё передаются все элементы строки.
